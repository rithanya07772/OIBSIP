# Temperature Converter

## Project Description

This project is a temperature converter created as part of the Oasis Infobyte Web Development and Designing internship.

It allows users to enter a temperature and convert it between Celsius, Fahrenheit, and Kelvin.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Celsius conversion
- Fahrenheit conversion
- Kelvin conversion
- Simple and responsive interface
- Input validation
- Conversion results displayed instantly
