# EcoNest – Sustainable Living Landing Page

## About the Project

EcoNest is a responsive landing page created as part of the Oasis Infobyte SIP Web Development & Designing internship.

The website represents a fictional sustainable lifestyle brand that promotes eco-friendly everyday products.

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- Responsive Media Queries

## Features

- Sticky navigation bar
- Responsive hero section
- Product showcase
- About section
- Call-to-action section
- Contact section
- Responsive footer
- Smooth scrolling navigation
- Mobile-friendly design
